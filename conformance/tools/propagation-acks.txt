# Propagation acknowledgements.
#
# tarn_propagate.py flags a passage that restates a rule a change touched and
# was not changed with it. Most such flags are real and the fix is to change
# the other passage. Where the pair is genuinely independent, record it here
# and say why — the same discipline COMPLETENESS_DISPOSITIONED and SKIPPED use.
#
# Format:  <source rule or §section> -> <site rule or §section>: <reason>
#
# An entry is a judgement on the record. A pair listed here without a reason,
# or with a reason that has stopped being true, is worse than no entry: it
# silences the one instrument that has caught this class of defect.
