# Quotations an ADR makes that are NOT in spec/tarn.md, and why that is correct.
#
# Format:  <adr number>|<prefix of the normalised quote>: <reason>
#
# An ADR that changes the spec quotes the text it replaces, which is absent by
# design. tarn_adr_quotes.py cannot tell that from an ADR whose description has
# drifted under it — the defect that hit ADR-0113, ADR-0115 and ADR-0117 — so
# each absence is recorded here with a reason a reader can check.

0117|The register carries a row for a condition exactly where: quotes §21.7's sentence AS IT READ BEFORE this ADR, which weakened the biconditional to its forward direction. Absent because this decision removed it.
0117|a conforming one: quotes the operational gloss's superseded comparison class. This ADR aligned the gloss with the formal definition, so the phrase is gone by design.
0117|in any form … alike: quotes R8's superseded Condition cell, which asserted the two limbs were one shape. This ADR splits them, so the framing is gone by design. (The ellipsis is the ADR's own elision, so this could never match verbatim regardless.)
0117|is not well-formed JSON either, so no two files could differ: quotes a comment in conformance/tools/vectordefs/r_rows.py, not the specification — the corpus author's counterargument, answered in the ADR. Not spec text and never was.
0117|so an unwitnessed condition is absent from it by that clause's own terms: quotes the conclusion this decision's OWN first draft left standing when it weakened the premise under it. Two audit lanes found the broken inference; the sentence was repaired and the ADR records what it used to say. Absent by design, and the reason the erratum exists.
0117|rather than in breach of them: quotes the ORIGINAL scoping this decision's first correction dropped and its second restored in different words. Absent because the sentence now ends "its absence is not the defect that clause names". Recorded so the erratum's account of both attempts stays checkable.

# The pre-round-30 audit of ADR-0118's repairs (2026-09-03) changed nine of the
# spans the ADR quoted as NEW text. Each is recorded here so the ADR's account
# of what it wrote stays checkable against what the audit then did to it.
0118|runs to MUST-level conditions, which §21 inventories: quoted as the new appositive; two audit lanes found it asserts that §21 inventories MUST-level conditions as a class, which §21.7 denies, and the clause was cut.
0118|which need not be the same check for every one of them: quoted as the new clause; "them" had two antecedents (the files, or the reader and verifier) and now reads "every one of those files".
0118|A shrink whose damage falls on a tile the new state no longer stores is precisely where: quoted as the repaired shrink sentence; "precisely where" was a biconditional the bar falsifies outside shrinks, and the sentence now states one direction with "only".
0118|the field widths at which §4 fixes the parse: quoted as the new §19.3 member; a parse convention stayed listed among validations, naming no check, and the member was dropped.
0118|caught by the rows for the fields that hold them: quoted as the claim the repair qualified; the qualified aside gave [R-ENC-06] the partially-caught shape §21.7 reserves for unwitnessed conditions, and the aside was cut.
0118|Neither obligation has a witness in the output alone, save: quotes the repaired witness sentence in the erratum; it keyed checkability to the compactor's implementation set, which the output does not carry, and was cut as the sentence's second false form.
0118|ask whether a breach can be made to leave behind a file: quotes §21.7's operational gloss in the erratum; its outer quantifier was ∃ where the definition's is ∀, and the clause was cut.
0118|the byte offset of any value within the decoded tile image: quotes the renamed list member in the erratum; it now reads "the byte offset — or, in a packed plane, the bit position — of any value".
0118|a relocated tile-index region: quotes the §20.5 Example's superseded keying in the erratum; the Example now keys on a region any of whose stored extents moved.
0118|a layer or a tile: quotes [R-ERR-04]'s superseded scope list in the erratum; the list now reads "a layer, a tile, or the record carrying a user-metadata document, as §18.2 assigns".
